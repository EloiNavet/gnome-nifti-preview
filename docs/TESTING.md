# Testing

All test data are synthetic phantoms generated by `reference/src/nifti_preview_ref/synthetic.py`
(`nifti-preview-ref make-fixtures DIR`). No subject data is used or downloaded.

| Suite | Command | What it covers |
|---|---|---|
| Rust unit + robustness | `cd backend && cargo test && cargo test --release` | header parsing and repairs, orientation, percentiles, label colours; 7 200 mutated/truncated files (real extreme float values, NIfTI-2, big-endian, 2D, 5D, every datatype) must fail cleanly within a deadline; vox_offset 0; bgzip |
| Hostile files | (same) `tests/hostile.rs` | huge `vox_offset` in a tiny gzip, giant slices, an 8 GB sparse `.nii`, a 300 MB mapped file, FIFO, `/dev/zero`, path replaced after open, lying gzip trailer, trailing garbage, decompression bomb, NaN sizes and affines, control characters in `descrip` |
| Spectroscopy | (same) `tests/mrs.rs`, and the FFT against a direct DFT | explicit chemical-shift references (including zero and negative shifts), standard uppercase nuclei and zero echo time; NIfTI-MRS single voxel with dephased coils and dynamics (upright NAA, Cr, Cho at their ppm), edit, ISIS, phase-cycle, indirect and user dimensions taken at index 0 (an edited pair whose difference matters), spectroscopic imaging with a spectrum per voxel, axis in Hz or points without frequency or dwell time, big-endian complex128 without orientation, metadata counts for enormous higher dimensions without building their index lists; JSON extensions that are invalid, huge or badly sized, data above the limit or truncated, too many points (refused before every FID is read) |
| Resampling | (same) `tests/resample.rs` | an oblique image in the anatomical modes: a linear function of the world coordinates survives the trilinear interpolation, labels come from the nearest voxel, RGB is interpolated per channel, black outside; the stored mode and flat or straight images keep the voxel grid; cursor carried from grid to grid, values of the nearest voxel |
| Protocol and sandbox | (same) `tests/protocol.rs`, `tests/sandbox.rs` | malformed, deeply nested and oversized requests, out-of-range indices, environment limits; in a child process, writes, exec, TCP, UDP, Unix sockets, socketpair and big allocations fail under the sandbox while reading and threads still work; an inherited socket is closed by `serve`; images at the limit still load |
| Values | (same) `tests/values.rs` | uint32, int64/uint64 and float64 labels stay distinct (exact readout, range, count, volume and colour; both NIfTI formats, byte orders and gzip); finite extreme/subnormal grayscale ranges keep contrast; compensated float32/float64 scaling is applied before reducing display precision (both NIfTI formats and byte orders); coordinates in mm for headers in mm, m and µm; `render --view` with an unknown view fails; under an inherited memory limit, a 64 MiB image gives an answer or an error, never an abort |
| Fuzzing | `cd backend && cargo +nightly fuzz run open_load_render CORPUS` | any file content through open, load, render and value (seeds: `python3 fuzz/make_seeds.py CORPUS`); 2 minutes in CI |
| Supply chain | `cd backend && cargo deny check`; `shellcheck -x -S warning` on every script | RustSec advisories, licences, sources; shell script lint |
| Reference + differential | `pip install -e "reference[test]" && pytest reference` | nibabel reference (orientation markers in 8 storage orders × 3 modes, windowing, labels, datatypes, 4D/5D, errors, protocol); then the Rust binary must reproduce it on 108 synthetic files: metadata, affine, plans, statistics, slices at 4 positions × 3 views × every mode and colormap (±1 grey level, labels and RGB exact), including oblique and random affines resampled onto the world axes, the cursor carried from grid to grid, values on the grid, error codes; label identifiers above 2^24 and 2^53, uint64 limits and float64 labels (also resampled); finite extreme contrast; spectra of 10 NIfTI-MRS files, one with edit conditions (relative error 1e-4) |
| GJS client | `NIFTI_PREVIEW_BACKEND=backend/target/release/nifti-preview gjs tests/gjs/test_client.js DIR` | pipelining, error mapping, missing binary, backend crash, response lines up to 8 MiB (a 9 MiB one refused, a 3 MiB one read), spectra inconsistent with their length refused, accessible descriptions, label identifiers in full (including decimal strings beyond 2^53), scroll coalescing, click navigation, mode switch, an oblique image resampled with its cursor kept across modes, an RGB image in colour and its L switch, spectroscopy (spectrum drawn, real part ↔ magnitude, range, the spectrum of the cursor voxel, metadata), 20 open/close cycles without leftover process; a scripted fake backend sending oversized, inconsistent, misnumbered or malformed replies, or none (deadlines); exceptions in viewer callbacks; unreadable settings |
| Sushi registry | `XDG_DATA_HOME=… xvfb-run gjs tests/gjs/sushi_mimehandler.js 46.0` | the real Sushi 46/50 renderer registry routes NIfTI to this viewer and every built-in type to its usual viewer |
| MIME | `tests/mime/test_mime.sh` | `.nii`, `.nii.gz` (spaces, upper case, invalid content) get the NIfTI types; `.tar.gz`, `.txt.gz`, `.gz`, PNG, text unchanged; removal restores the defaults |
| Install | `tests/install/test_install.sh [BINARY]` | Cargo-reported executable outside the source target directory; expected files, idempotent reinstall, upgrade cleanup, exact rollback of the home directory, other MIME packages preserved, "Open With" cases; root refused, relative XDG paths, a manifest pointing outside our files, invalid or symlinked `mimeapps.list`, viewers in folders others can write to, archive tools inherited from gzip not offered for `.nii.gz` without a viewer (and restored on uninstall), viewers in PATH or behind a desktop entry that others can change, folder names with quotes, `$()`, backslashes and backquotes (launched with the file), a home folder with `%`, quotes and `$` (the "no viewer" launcher still runs), a link planted in our folder that the manifest points through, `mimeapps.list` with comments and empty groups restored byte for byte (edits between installs kept even when a later install discovers a viewer; both pre-existing and installer-created files, permissions preserved), a GNOME desktop whose `gnome-mimeapps.list` makes Files the default for gzip (the default becomes "a NIfTI viewer…", replaced by a viewer installed later, removed on uninstall), restart of this session's previewer only |
| One-command install | `tests/install/test_get.sh [BINARY]` | `get.sh` through a pipe against a local release built by `tools/package.sh`: curl and wget-only installs, upgrade, `--uninstall` and the copied `uninstall.sh` restore the home directory, corrupted download, a `.sha256` naming another file and network errors install nothing, no use of `/tmp`, root refused, missing Sushi prompts and stops cleanly |
| Real Sushi | `tests/integration/sushi_xvfb.sh DIR OUT [BINARY]` | see [COMPATIBILITY.md](COMPATIBILITY.md), plus the metadata panel shown once complete, 45 rapid file changes leaving at most one backend, spectra (L and Z redraw), keyboard only (V then Page Down) and the "Open With a NIfTI viewer…" button on a simulated Ubuntu desktop; writes screenshots to OUT |

CI runs both the Rust tests and Clippy with stable and the Rust 1.85 MSRV, with
and without default features. Local lint: `cargo clippy --all-targets --locked -- -D warnings`
(and again with `--no-default-features`).

The shell tests run in a throw-away home folder with every XDG directory inside
it (`tests/lib/home.sh`): they never touch the real home folder, its
`mimeapps.list` or its running previewer.

The real-Sushi test needs `gnome-sushi gjs xvfb xdotool imagemagick x11-utils
dbus-x11 procps python3`. CI runs it on Ubuntu 24.04 (Sushi 46), 26.04 (Sushi 50)
and 26.10 (Sushi 51, allowed to fail).

## Checking on your desktop

1. Run the install command from the README (or `./install.sh` from a clone).
2. In Files, select a `.nii.gz` and press Space: three slices and the metadata appear.
3. Scroll over each view, click in one view, press O, L, C, then V and Page Down; check the R/L letters.
   On a segmentation, a click shows the label and its volume. On a NIfTI-MRS
   file, the spectrum appears; press L and Z.
4. Press Space: the preview closes; `pgrep -x nifti-preview` prints nothing.
5. Press Space on a PDF and a PNG: their usual previews still appear.
